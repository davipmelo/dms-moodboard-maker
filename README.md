O DM'S Moodboard Maker é uma solução vibecodada para um problema que eu tenho diariamente no trabalho: construir moodboards de forma rápida e fácil que tenham suporte à diversos tipos de arquivo como gifs, jpgs, webps, entre outros. Ele também permite fazer a exportação em jpg, pdf ou mp4, algo que até então eu não tinha encontrado pela internet.

Nada aqui foi escrito à mão, então é esperado que a aplicação tenha uma série de bugs, pretendo corrigir cada um deles conforme eu for encontrando.
